# Legacy prepared-patch experiment

**These files are not used by the current interview or repair queue.** Loop now plans and implements participant-requested changes with live coding workers; see [the current architecture](../docs/ARCHITECTURE.md).

This directory preserves an earlier experiment that mapped issues to two prewritten source patches: shortlisting and size measurements. `manifest.json` and `scripts/preverify-prepared.ts` belong to that experiment. They are retained as development history and must not be described as fresh AI-generated edits.

The patch files include diff context and should not be reformatted as ordinary source files. The earlier package command for preverification is no longer part of the active app's scripts.
